🎯 核心要点

  • 两次 LLM 意图分类：第 1 次分 A/D，第 2 次（仅 D 类）分 simple/complex
  • 三条管道完全独立：A 类走知识库，D-simple 走工具调用，D-complex 走 RCA 诊断
  • D-simple 不会转入根因分析：查不到 Skill → 直接结束；查到了 → 调工具 → 结束
  • D-complex 不会走 Agent Loop 调工具：查到 Skill → RCA Engine 分步执行 → 生成报告
  • 唯一的共享回退：两者在「没查到 Skill」时都回退到 _run_agent_loop(None) 做 LLM 自由推理

web.py → classify_user_intent

① 前端 → 后端：用户消息
类型 纯文本 string
传输 WebSocket ws.send(message)
示例 "查看 rocketmq broker pod"
📦
② 意图分类请求 → LLM
类型 messages: list[dict]
内容 [{"role": "user", "content": intent_prompt}]
参数 model, max_tokens=1000, temperature=0.1
返回 "A" 或 "D"
📦
③ Skill 向量库检索
输入 user_input: str, limit=4
输出 list[dict]：[{text, metadata: {skill_name, description, ...}}]
后处理 _rerank_route_candidates() → 取 Top1
📦
④ Skill 上下文构建 (additional_context)
内容结构
  • # 运维 Skill 参考: get_rocketmq_pods
  • 描述: 获取 RocketMQ 相关 Pod 列表
  • 类型: sop
  • ## 参考排查步骤: 各步骤 type / tool / prompt
  • ## 可用工具: kubectl_get_pods
  • ## 【重要指令】 必须立即调用 kubectl_get_pods 仅单工具时
📦
⑤ Agent Loop 消息组装
ContextBuilder.build_messages() 构建最终 LLM 请求：

messages 数组结构

  • [0] system: build_system_prompt() + "\n\n## Additional Context\n{additional_context}"
  • [1] user: 用户原始输入文本

tools 数组

  • 通过 tool_names_filter 筛选：get_definitions_by_names(filter)
  • 每个工具包含 name, description, parameters (JSON Schema)
📦
⑥ LLM 响应 → 工具执行 → 结果
LLM 响应 response.content + response.tool_calls

若有 tool_calls：
_repair_tool_call() → tools.execute(name, args) → 拼接结果

若无 tool_calls：
_fallback_exec_on_empty_response() → 推断命令 / 提取代码块自动执行

📡 流式推送 通过 stream_callback 实时发送 JSON 到前端：
  • type: "stream_chunk"
  • content_type: "tool" | "text" | "reasoning" | "completion"
  • tool_name, tool_status, tool_result, tool_args
📦
⑦ 最终输出 → 前端渲染
最终文本 response 通过 websocket.send_text() 发送
完成信号 {"type":"stream_chunk","content_type":"completion","is_completed":true}

前端 ws.onmessage 根据 content_type 分类渲染：
  • tool → 工具调用卡片（开始/成功/失败）
  • knowledge → 知识库检索状态
  • text → Markdown 渲染
  • completion → 恢复输入框可用
